# Gates before a wider launch

1. VGuard on actual Android phones: fresh selected-app block/unselected-app allow/stop-restore; IPv4/IPv6, DNS, bypass, pre-existing connections, VPN revocation, sleep, network switching, process stop, upgrades and accessibility. Record exact build and device.
2. VVault/VRelay on real Android and iPhone browsers: round-trip, wrong passphrase, tampered envelope, import/download/share, offline installation and offline reload, memory/clipboard handling, accessible controls.
3. Independent review of crypto format, Android enforcement, web delivery and feedback storage; fix and retest findings.
4. Real beta feedback. Triaged defects, published release notes and regression results.
5. Final brand/domain checks, operating identity and appropriate published legal/privacy details before commercial launch.
6. Costed paid offering and explicitly accepted billing/trial flow. No automatic conversion is active in this beta.
7. Store distribution, release/update signing process and reproducible-build work. No store acceptance or bit-identical build is currently claimed.
