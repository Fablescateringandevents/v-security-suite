# Contributing

Open a focused issue or pull request with version, OS, expected behaviour, actual behaviour and a minimal synthetic reproduction. Never include signing keys, credentials, private messages or personal records. For vulnerabilities, see SECURITY.md and use the private form.

Run the relevant existing tests. Add tests for a specific meaningful failure; do not inflate assertion counts or describe host stubs as physical-device tests. Distinguish observed results from assumptions. Preserve the local-processing boundary and do not add trackers.

Contributions to original project code are under GPL-3.0-or-later. Do not submit third-party code without compatible licensing and attribution.
